# BubblePhysics v1.0.0 -> HEAD: różnice publicznego API z `swift-api-digester -diagnose-sdk`.
# Moduły: BubblePhysics, BubblePhysicsModel (typy modelu), BubblePhysicsMetalRender. Zrzut modułu nie obejmuje re-eksportów,
# więc typy modelu leżą w BubblePhysicsModel. Moduł BubblePhysicsAssets jest nowy w 2.0.0 i nie ma odpowiednika w v1.0.0.
# Zrzut obejmuje też deklaracje `package` (były `package` już w v1.0.0, nie są publicznym API); docs/MIGRATION-v2.md opisuje je osobno.
# Zamienniki każdego symbolu opisuje docs/MIGRATION-v2.md (test MigrationGuideTests).
# Powtarzalne: ten sam HEAD daje ten sam plik (polecenia z katalogu głównego repozytorium, ścieżki względne).
# Generowanie (wiersze `# $ ` to polecenia; plik powstaje z ich wyniku):
# $ [ -d .build/v1-worktree ] || git worktree add --detach .build/v1-worktree v1.0.0
# $ swift build --package-path .build/v1-worktree --target BubblePhysics --target BubblePhysicsModel --target BubblePhysicsMetalRender
# $ swift build --target BubblePhysics --target BubblePhysicsModel --target BubblePhysicsMetalRender
# $ mkdir -p .build/api-dump/v1
# $ for m in BubblePhysics BubblePhysicsModel BubblePhysicsMetalRender; do xcrun swift-api-digester -dump-sdk -module $m -I .build/v1-worktree/.build/debug/Modules -sdk "$(xcrun --sdk macosx --show-sdk-path)" -target "$(uname -m)-apple-macosx13.0" -o .build/api-dump/v1/$m.json; done
# $ for m in BubblePhysics BubblePhysicsModel BubblePhysicsMetalRender; do xcrun swift-api-digester -diagnose-sdk -print-module -module $m -I .build/debug/Modules -sdk "$(xcrun --sdk macosx --show-sdk-path)" -target "$(uname -m)-apple-macosx13.0" -baseline-path .build/api-dump/v1/$m.json; done
